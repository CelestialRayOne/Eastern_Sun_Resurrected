Eastern Sun Resurrected

Мод полной конверсии для Diablo II: Resurrected
Помазания это уникальные бонусы, которые получают, трансмутируя определенные реагенты для куба с некоторыми предметами.
Для уникальных амулетовпомазания получают, трансмутируя все части тела босса Глаз Шторма
(Демонический рог Диабло, Демонический Глаз Баала, Демонический мозг Мефисто) с Уникальный амулет ради разового бонуса.
Для обычного/Магия/Редкие/Созданное/Комплектные надеваемого снаряжения без рунного слова помазания получают, трансмутируя Орб аннотации с редким предметом.
В отличие от порчи, помазание не может испортить предмет.
Трансмутировав предмет с нужными реагентами для куба, нужно трансмутировать его еще раз, чтобы действительно помазать.
