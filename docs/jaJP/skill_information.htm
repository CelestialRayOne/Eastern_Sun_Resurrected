スキル 自己紹介
アロー、炎/冷気/雷/魔法強化アロー 武器ダメージの100%を与える、貫通しない単純な矢です。属性強化版は物理ダメージの100%を対応するダメージタイプに変換します。
アックススロー、炎/冷気/雷/魔法強化アックス 武器ダメージの100%を与える、貫通しない単純な斧です。属性強化版は物理ダメージの100%を対応するダメージタイプに変換します。
炎/冷気/雷/毒/魔法/風のサージ 小範囲に即時の呪文ダメージを与えるスキルです。各スキルは同属性のすべての呪文からシナジーボーナスを得ます（例：ファイアサージはフレイムバーストやボルケーノなど、直接ダメージを与えるすべての炎呪文からシナジーを得ます）。他の発動スキルと異なり、クロスボウのボーナスダメージを引き継ぎます。
エレメンタルサージ 炎・冷気・雷・魔法・風のサージを5つで1つにまとめたもの。
炎/冷気/雷/魔法/風のブランド 対象の敵に烙印を付け、0.4秒後に武器ダメージの100%を対応する属性に変換して与えるスキルです。
炎/冷気/雷/魔法/無属性のスパイクノヴァ 武器ダメージの100%を対応する属性に変換して与える、64本のスパイクのノヴァを放つスキルです。
タイムラプス 発動または詠唱時に使用者を回復するだけのスキルです。レベル = 回復率（例：レベル10 = 最大ライフの10%を回復）。
スーパーノヴァ 画面全体に広がるノヴァで、武器ダメージの150%を雷ダメージに変換して与え、すべての敵をノックバックさせます。
自然の精霊の達人 レベルごとに物理耐性1%とライフ5%を与えるパッシブスキルです（フェラルマスタリーのボーナスと加算）。
ウォームアップ レベルごとに攻撃速度2%、移動速度2%、詠唱速度2%、マナ再生10%を与える強化です。さらにレベルごとに毎秒約10のライフを回復します。
ブレード・オブ・アイス/クロー・オブ・サンダー/フィスト・オブ・ファイアのディスチャージ 発動時に3チャージのチャージスキルを模擬的に放出する発動スキルです。通常のスキルと同じシナジーを受けます。物理フィニッシャーのディスチャージ発動とは異なり、習得したスキルではなく発動スキル自体のレベルを使用します。
炎/冷気/雷ダメージのオーラ 影響下のパーティーメンバーに、レベルごとに該当属性の呪文ダメージ5%を与えるオーラです。
炎/冷気/雷の貫通オーラ 近くの敵の該当属性への耐性を、レベルごとに1%下げるオーラです。
ドラゴンフューリー/エクスキュートのディスチャージ アイテムの発動効果で、発動すると完全にチャージされた現在レベル（発動レベルではなく習得スキルのレベル）のドラゴンフューリー/エクスキュートを敵に放出します。
物理ダメージのトロフィー 強化ダメージ800%と攻撃への物理ダメージ50-100を与える強化です。20秒間持続します。
スピードのトロフィー 基本攻撃速度と走行/歩行速度100%、詠唱速度上昇100%、ブロック速度上昇100%、ヒットリカバリー速度上昇100%を与える強化です。20秒間持続します。
呪文ダメージのトロフィー 呪文ダメージ300%を与える強化です。20秒間持続します。
持続のトロフィー 最大ライフと最大マナを150%増加させる強化です。20秒間持続します。
抵抗のトロフィー 元素耐性と毒耐性100%、物理耐性と魔法耐性50%を与える強化です。20秒間持続します。
ステータスのトロフィー 全能力値+150を与える強化です。20秒間持続します。
