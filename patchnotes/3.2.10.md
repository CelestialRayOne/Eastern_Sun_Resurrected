**Launcher**

* Improved how the launcher operates on your files. It should no longer delete global plugins you have installed for other mods. Also, Eastern Sun no longer uses global plugins since this mod experience is tailored directly by the included plugins and external plugins are not intended to work with Eastern Sun due to game balance or existing systems breaking.

**Bug Fixes**

* Added missing sprites for some unique items.  
* Fixed terror zones groupings.  
* Fixed Mirrored Blades’ description and damage display.
* Fixed a bug where achievement were not counted on steam if the game was started through launcher.
* Global plugins no longer apply when ESR is running. This should stabilize the game a bit.

**Monsters**

* **Stone Skin** \- Added an overlay to make it more visible while active. Reduced stun duration on hitting the enemy from 1 second to 0.2 seconds.  
* Throne room diablo has \~40% less life now.

**Warlock**

* **Bind Demon** \- You can now bind nihlathak superuniques’ minions as well.
